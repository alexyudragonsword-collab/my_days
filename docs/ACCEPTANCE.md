# 验收标准覆盖表

本表把 PRD 中的验收标准 AC-001 至 AC-040 映射到可重复执行的检查。

- **服务端集成测试**：`npm run verify`（构建 + `tests/server.test.mjs`，针对真实构建产物启动服务）
- **浏览器端到端测试**：`npm run test:e2e`（`tests/e2e/acceptance.spec.ts`，每次使用全新数据目录）
- 涉及"关闭浏览器 / 重启电脑"的标准，通过"完全关闭服务进程后从同一 SQLite 文件重新读取"做等价自动化——这是应用能控制的持久化边界，真实重启不会引入额外内存状态。

| 标准 | 内容摘要 | 覆盖方式 |
| --- | --- | --- |
| AC-001 | 本机启动无需联网登录 | 服务端测试健康检查；E2E 打开首页 |
| AC-002 | 断网核心功能可用 | 构建产物无远程资源引用（前端全部本地打包）；人工断网抽查 |
| AC-003 | 局域网其他设备不可访问 | 服务只绑定 127.0.0.1（代码约束）；服务端测试验证拒绝外部 Origin 写入 |
| AC-004 | 九个页面与分组导航 | E2E 逐一进入九个页面 |
| AC-005 | 各模块建记录后刷新仍在 | 服务端测试写入七个模块并重读；E2E 刷新页面验证 |
| AC-006 | 关浏览器后数据仍在 | 数据在 SQLite 不依赖浏览器存储；E2E 重载等价验证 |
| AC-007 | 重启服务后数据仍在 | 服务端测试重启服务进程后重读 |
| AC-008 | 重启电脑后数据仍在 | 与 AC-007 同边界（进程完全退出后重读），人工在真机复查 |
| AC-009 | 显示数据文件路径/大小/时间 | E2E 检查设置页；`/api/status` 返回真实 stat |
| AC-010 | 写入失败不得显示已保存 | 写接口失败返回非 2xx，前端显示"保存失败"（代码路径）；人工制造只读磁盘复查 |
| AC-011 | 有时间事项进时间线 | E2E |
| AC-012 | 无时间事项进待安排 | E2E |
| AC-013 | 完成状态与进度同步 | E2E |
| AC-014 | 模块行动加入今日计划并可返回 | E2E |
| AC-015 | 来源改名两处同步 | 服务端测试验证 source_title 实时解析 |
| AC-016 | 首页摘要可点击跳转 | E2E 导航覆盖；摘要行 route 均指向模块页 |
| AC-017 | 备忘持久且可转换 | E2E |
| AC-018 | 计划事项完整操作 | 服务端 CRUD 测试 + E2E 创建/完成/删除 |
| AC-019 | 自媒体五阶段流转 | E2E 看板列数与卡片；服务端 stage 字段读写 |
| AC-020 | 开发模块专属数据 | 服务端测试（项目/类型字段） |
| AC-021 | 咨询模块专属数据 | 服务端测试（客户）+ 浏览器冒烟（历史记录） |
| AC-022 | 健身逐组记录与上次数据 | 服务端模板字段测试 + 浏览器冒烟 |
| AC-023 | 饮食计划/实际分开与汇总 | 浏览器冒烟（kind 字段区分 + 汇总卡） |
| AC-024 | 游戏状态与游玩记录 | 服务端测试（状态/下一目标字段） |
| AC-025 | 各模块保存专属信息 | 服务端测试逐模块校验专属字段往返 |
| AC-026 | 全局搜索按模块分组 | 服务端测试 + E2E Ctrl+K |
| AC-027 | 删除进回收站可恢复 | 服务端测试 + E2E |
| AC-028 | 永久删除需二次确认 | E2E（取消确认后记录仍在） |
| AC-029 | 设置刷新后生效 | 服务端测试（重启后读回）+ E2E（外观/主题） |
| AC-030 | 空数据模块显示空状态 | E2E |
| AC-031 | 手动备份生成独立文件 | 服务端测试 + E2E |
| AC-032 | 备份命名与保留标记持久 | 服务端 PATCH 接口测试（manifest 独立于主库） |
| AC-033 | 每日自动备份不重复 | 服务端测试（启动后恰好一份自动备份） |
| AC-034 | 超 30 份清理、保留标记不清理 | 备份清理逻辑（`cleanupAutoBackups`），会话内脚本验证过；可人工铺文件复查 |
| AC-035 | 恢复回到备份时状态 | 服务端测试 |
| AC-036 | 恢复前生成安全备份 | 服务端测试 |
| AC-037 | 无效备份拒绝恢复 | 服务端测试 |
| AC-038 | 备份失败显示提示 | `/api/status` 返回 lastError，顶栏显示（代码路径）；人工模拟写失败复查 |
| AC-039 | 导出含各模块记录且不改主数据 | 服务端测试（ZIP 内容 + 前后行数对比） |
| AC-040 | 手动保存落盘与完整性检查 | 服务端测试 `/api/save` |

需要人工复查的仅有：真实断网（AC-002）、真机重启（AC-008）、只读磁盘（AC-010）、备份写失败提示（AC-038）和大量备份清理（AC-034），其余全部自动化。
